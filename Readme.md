# Personal Finance Management System

A simple app to help you track money, set budgets, and see where your cash goes.

## Key features
- Track income and expenses
- Organize transactions by category
- View monthly summaries and balance
- Set budgets and get basic alerts
- Export/import data (CSV)

## How it works
- Add transactions with date, amount, and category  
- See running balance and category totals  
- Review monthly reports and adjust budgets

## Quick start
1. Clone the project  
2. Install dependencies  
3. Run the app and open it in your browser
